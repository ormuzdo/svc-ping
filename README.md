# svc-ping

Зовнішня перевірка доступності сервісу.

`.github/workflows/uptime.yml` кожні ~5 хв запитує адресу з секрета `PING_URL`; якщо у відповідь
не `200` (з одним ретраєм проти випадкового флапу) — шле повідомлення в Telegram.

Секрети репо: `PING_URL`, `TG_BOT_TOKEN`, `TG_SUPPORT_CHAT`. У файлах ні адрес, ні токенів нема —
GitHub тримає їх зашифрованими й маскує в логах запусків.

**Перевірити алерт вручну:** Actions → *uptime* → *Run workflow* → `force_url` = будь-яка адреса,
що віддає не 200 → у Telegram має прийти «🧪 ТЕСТ … 🔴».

`keepalive.yml` раз на ~20 днів комітить мітку, щоб GitHub не вимкнув крон після 60 днів без активності.

Репо публічний: у приватних Actions-хвилини платні, а крон раз на 5 хв з'їв би безкоштовний ліміт
за тиждень. Тому тут не лежить нічого, крім цих двох файлів.
